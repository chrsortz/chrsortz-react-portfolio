# Christian — React Portfolio

Minimalist, interactive and responsive portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Customize

Edit `src/main.jsx` to update:
- Name
- About text
- Skills
- Projects
- Email
- GitHub
- LinkedIn

Replace the placeholder contact links before publishing.
